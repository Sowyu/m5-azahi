## ACIPC static transport tables — primary source, not guessed registers

Base: `/System/DriverKit/System/Library/PrivateFrameworks/AirshipDK.framework/`.

- `t2026-CentauriAlpha.plist`: SHA256
  `030f2ad01853938932bc98accb6763b02e38e8b77b77885126d43fa3f861278f`.
- `t2026-CentauriControl.plist`: SHA256
  `1364719a8d95b4323b3b65b7f975ec04cee96608b89d37392271c64b0dbff256`.

Both declare vendorCentauri, chipsett2026, protocolacipc; main IPC version768
(0x300). Exact live-target firmware/config selection still needs verification.
**Offsets below are bank-relative config fields, NOT CPU physical addresses,
not a proven bank-to-BAR mapping, and not permission to read/write hardware.**

Alpha:

- Execution-stage register bank0+0x8; OS stage2, abort3.
- IPC status0xc; context address low/high0x10/0x14; DMA window low/high/size
  0x18/0x1c/0x20; sleep control0x1024; IPC control0x1028.
- Shared-constant doorbells, value1, width4: control0x1004, TX0x1030, RX0x1050.
- Interrupt vectors: main0, control2, TX3 with count5, RX8, low-latency RX9.
- Transfer index count192; completion index count234; scratch5242880 bytes;
  main transfer/completion ring size16; IPC running timeout2000.
- 11 transfer-ring definitions,10 completion-ring definitions,2 completion
  groups. Counts are definitions, not expanded hardware queue counts.
- Command request transfer id1/size64, response id2/size192, event id3/size96;
  corresponding completion sizes1024. Management id4/size192.
- DataTX transfer id25/count166/size2048, completion id76/count12/size2048;
  EAPOL transfer id24 uses dataTX completion. Footer sizes16.
- DataRX transfer id12/count1/size2048, completion id15/count27/size2048;
  low-latency and monitor rings are separate. Some RX is out-of-order.
- Errata: ignore_zeroed_cd=true, window_base_mask=0xffffffffff (40bits).

Control:

- Execution-stage register bank0+0x8000. Stages ROM0, boot1, OS2, abort3,
  preboot4, low-power boot6 and low-power OS7.
- ROM and boot image address low/high0x8044/0x8048, size0x804c,
  response0x8040. ROM image doorbell0x9000; boot image doorbell0x9070.
  Both image_table=true, success_code1; ROM failure codes2..7.
- Metadata declares ROM nonce/hash, chip-info and platform fields. No live
  values read, no nonce/signature bypass attempted or needed by this audit.
- OS IPC status0x8050, context low/high0x8054/0x8058, sleep0x9078,
  control0x907c; window low/high/size0x4014/0x4018/0x401c.
- One main interrupt vector0; transfer index count13, completion index count1.
- Errata: ring_header_footer_scaling=true, skip_window_configuration=true,
  window_base_mask=0xffffffffff. Do not apply Alpha's window setup to Control.

Need decode actual context/ring descriptor layouts, publication order, status
values, firmware container/boot sequencing, command/event payloads and Linux
DMA ownership before producing an enabling driver. Counts/offsets alone are
insufficient, and enabling firmware-controlled DMA prematurely risks SSD root.
